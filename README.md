# navier-stokes-ko

OpenAI가 공개한 *Finite time blowup for Navier-Stokes* 원본 PDF를 Codex를 이용해 한국어로 번역한 자료이다.

- `navier-stokes-ko-complete.md`: 수식과 그림을 포함한 한국어 Markdown 번역본
- `navier-stokes-ko-complete.pdf`: 수식과 그림을 포함한 한국어 PDF 번역본
- 원문: [OpenAI, *Finite time blowup for Navier-Stokes*](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf)

번역문은 원문의 절, 정리, 보조정리, 식 번호와 수식을 보존하도록 구성했다. 본문은 한국어 평서체로 옮겼으며 별도의 해설이나 평가를 덧붙이지 않았다.

## 안내

이 번역은 참고용이다. 수학적 내용의 정확한 해석과 인용에는 원문을 함께 확인해야 한다.
